Deployment ka mechanism

Is portal mein deployment WinRM aur PowerShell ke through hoti hai.

1. Aap deployment details dete ho

  • Target server
  • IIS site aur application name
  • Source folder: nayi published application files
  • Target folder: jahan IIS application chalegi
  • New site ho to port aur optional hostname
Abhi source files target server par pehle se honi chahiye. Portal aapke PC se remote server par package upload nahi karta.

2. Portal pehle review karta hai

Portal saved credentials se WinRM connection banata hai. WinRM Windows ka remote-management mechanism hai, jiske zariye target server par predefined PowerShell script chalti hai.

Script check karti hai:

  • Source folder mein web.config hai?
  • Paths safe hain?
  • IIS site/application exist karti hai?
  • Application pool dedicated hai?
  • New site ka port/hostname conflict to nahi karta?

3. Aapse confirmation leta hai

Situation ke mutabiq message aata hai:

SituationApproval ke baad action
Site nahi haiNew site/application create hogi
Site hai, application nahiExisting site mein application add hogi
Dono hainExisting application update hogi

Approval se pehle files replace nahi hoti.

4. Background deployment chalti hai

Confirmation ke baad database mein deployment record banta hai. Background worker:

  1. Connection aur approved configuration dobara check karta hai.
  2. Existing dedicated application pool running ho to stop karta hai.
  3. Target folder ki existing files ka backup banata hai.
  4. Target ki files replace karke source ki nayi files copy karta hai.
  5. Zaroorat ho to IIS site/application/pool create karta hai.
  6. Pool aur site start karke IIS state verify karta hai.

Browser tab band karne se background deployment cancel nahi hoti.

5. Success ya rollback

  • Success: result aur duration deployment history mein save hote hain.
  • Failure after changes: script backup se purani files restore karne aur newly created IIS objects remove karne ki koshish karti hai.
  • Rollback successful hua ya failed, result mein bataya jata hai.
